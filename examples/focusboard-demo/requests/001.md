# P001 — 基础看板（FocusBoard 第一轮产品计划）

## 目标

实现 FocusBoard 最小可用任务看板：三列（todo / doing / done）+ 任务
CRUD + 状态切换 + 本地保存 + 简单 VM 界面 + 用法 Wiki。

## 增量需求

1. 任务卡片字段：标题（必填，非空）。本轮不需要其他字段。
2. 操作：添加任务（进 todo 列）、重命名任务、删除任务。
3. 三列固定为 todo / doing / done；任务可在列间移动（状态切换），每列
   内按创建时间正序排列。
4. 本地保存：任务及所在列跨应用重启保留（关闭 Canvas 再启动后数据仍在；
   界面提供"清空全部"入口，需二次确认文案）。
5. VM 界面：三列布局在 480x680 Canvas 窗口可读可用；列标题显示当前
   任务数。
6. 用法 Wiki：`docs/wiki/usage.md` 记录用户视角的操作说明。

## 验收口径（演示驱动将按此断言）

- 添加 → todo 出现新任务；重命名后标题更新；删除后消失。
- 状态切换：todo→doing→done 双向可操作。
- 关闭 Canvas 再启动：任务与所在列原样保留（跨启保存为硬验收）。
- 列头计数与实际任务数一致。
