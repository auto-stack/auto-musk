# P002 — 限制并行（FocusBoard 第二轮产品计划）

## 目标

在 P001 基础上引入 WIP 限制：doing 列最多 3 个任务，超限拒绝并给可见
解释；规则沉淀为 Specs，配测试与 Wiki。

## 增量需求

1. doing 列上限 3（本轮固定值，不做配置界面）。
2. 达到上限时：拒绝第 4 个任务进入 doing（含从 todo 拖入/移入的所有
   入口），原状态不变，并给用户可见的拒绝解释（文案说明上限与当前数）。
3. 完成或移出 doing 后允许再进入。
4. 界面可见计数：doing 列头显示 `n/3`；接近上限（n=3）时有可感知提示。
5. 补规则 Spec（`docs/specs/`，WIP 限制为权威规则）、对应测试、Wiki
   更新（规则说明 + 与 P001 用法的衔接）。

## 验收口径

- doing=3 时第 4 项进入被拒，原任务状态与所在列不变，用户可见解释。
- 移出一个 doing 任务后可再进入一个。
- P001 全部行为不退化（CRUD/三列/跨启保存回归）。
