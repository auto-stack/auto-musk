# P003 — 可配置规则（FocusBoard 第三轮产品计划；新会话）

## 目标

新会话续接：从已有 Specs 与交付工件出发（不带前两轮聊天/设计推理），
把 P002 的固定上限改为可配置规则，并改善相关文案。

## 增量需求

1. doing 上限可由用户设置为 1~5 的整数并持久保存（跨重启保留）。
2. 非法输入（非整数、越界）拒绝并保留原设定，给可见解释。
3. 上限降到当前 doing 数量以下时：现有任务保留原列不删，但阻止任何
   新增进入 doing，直到数量回落；提示文案说明当前数量与上限。
4. 改善 P002 的拒绝解释文案（更具体：指出当前 n/上限、如何释放）。
5. 规则 Spec 更新（可配置化后的权威口径）、测试、Wiki 更新。

## 验收口径

- 3→2 降限：现有 3 个 doing 任务保留，新增被阻止且解释可见。
- 无效输入（0、6、abc、小数）拒绝，原设定不变。
- 重启后设定与任务均保留；P001/P002 行为回归通过。
