### 关键决策

- 模糊命中只在规范化空间比对;回写按行组:未触达行保留原始字节,触达行组从规范化空间重写(防规范化污染全文件)。
- 歧义(>1 次)即失败 + 重叠即拒绝,不放宽;五类报错(not found/N 次/空 old/无变化/重叠)自带下一步指引。
- 入口垫片兼容三种模型怪癖:edits 发成 JSON 字符串/单对象/旧式顶层 old_string+new_string。
- 新依赖 unicode-normalization(NFKC)与 dashmap(per-path 锁),均纯 Rust。
- PLAN-027 未落地:diff/truncation 元数据留三处 `// PLAN-027 挂接点` 标注。
