## Original content

1. **wait 与 drain 必须并发 join**(计划未预见的死锁点):串行"先 wait 后排空"在大输出下死锁——管道+channel 写满→子进程 write 阻塞→永不退出→wait 挂起;`futures::join!(child.wait(), drain)` 修复,840KB 流测试实测。
2. 原始 mpsc `tx` 在 spawn 读任务后立即 drop,否则 drain 的 `recv()` 永不返回 None。
3. 100ms 节流(pi BASH_UPDATE_THROTTLE_MS)推**尾部快照**(非增量),前端替换式渲染;丢帧可接受(partial 是易态,broadcast Lagged 继续)。
4. 临时文件失败优雅降级(与 pi throw 分野):记 temp_error,尾注给说明文本不给假路径。
5. Windows 树杀 `start /b` 孙进程实测 taskkill /T /F 覆盖;Job Object 为兜底预案(DEBT-040-2)。
