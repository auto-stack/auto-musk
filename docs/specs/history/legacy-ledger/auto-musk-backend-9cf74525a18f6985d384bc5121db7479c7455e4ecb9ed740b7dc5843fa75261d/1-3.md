# Legacy Spec: run_command 对齐 pi bash——tokio 流式输出、超时、进程树终止、尾部截断+临时文件、ToolUpdate SSE 实时进度与 CommandRunner 接缝 — 架构

## Original content

1. 新模块 `command_runner.rs`:`CommandRunner` trait(Ash 后座替换契约五条:安全不在 runner 层/流式 on_data/超时杀树/退出码透明/cwd-env 不逸出)+ `LocalRunner`(tokio 双读任务并发拉流→合并通道,Windows `cmd /C`/Unix `sh -c`,Unix `process_group(0)`+killpg,`kill_on_drop` 兜底)。
2. 新模块 `output_accumulator.rs`:滚动尾部缓冲(2×50KB)+流式 UTF-8 解码(跨 chunk 多字节边界安全,非法字节 U+FFFD)+超限全量落临时文件(路径随尾注给模型)+pi snapshot 语义。
3. `tool_context.rs`:`ToolContext` 增 `progress: Option<ProgressSink>`(进程级 broadcast 总线 sender+run_id;chat=session_id/relay=run_id),4 个构造点全接(chat SSE 桥接任务 bus→mpsc;relay SSE 原样透传)。
4. `relay/store.rs`:`RunEvent` 16→17 变体(+`ToolUpdate{run_id,tool_call_id,tool_name,partial}`)——SSE-only 易态,不落 run.events、不镜像 conversation turns;auto_generated/relay_store.rs wire parity 手补。
5. `tools.rs` RunCommand 重写:白名单/confine 零改动,timeout 参数(pi resolveTimeoutMs 校验)→ runner → 累积器快照 → pi formatOutput 三态尾注 → 超时/非零退出码 = `ToolError::Exec`(appendStatus:输出保留+状态追加);progress 存在时注入 MUSK_SESSION_ID。
